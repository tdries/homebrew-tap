# tdries/homebrew-tap

Homebrew formulae for [Tim Dries](https://github.com/tdries)' tools.

```bash
brew install tdries/tap/<formula>
```

| Formula | |
|---|---|
| [`popr`](https://github.com/tdries/td-claude-plugin-popr) | Clickable macOS notifications for Claude Code |

Formulae here are updated automatically by the source repo's release workflow.
Open issues against the tool's own repository, not this one.
